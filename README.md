# Projeto Harve

Projeto acadêmico inicial mantido como registro histórico de aprendizagem.

## Contexto

Este repositório foi criado durante uma fase inicial de estudos em desenvolvimento web e contém um protótipo simples em HTML.

## Estado do projeto

O código presente aqui não representa o nível atual dos meus projetos. O repositório permanece disponível para registrar a evolução dos estudos ao longo do tempo.

Projetos mais recentes do perfil apresentam aplicações com JavaScript moderno, arquitetura modular, testes, acessibilidade e desenvolvimento com React.
